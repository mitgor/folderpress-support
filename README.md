# FolderPress Support

FolderPress is a free macOS utility from **Woodenshark LLC** for transparent compression of selected local files and folders. Requires macOS 14 or later. Supports Apple silicon and Intel Macs.

## Help and support

Email **support@woodenshark.com**, or [open a support issue](https://github.com/mitgor/folderpress-support/issues).

Include your macOS version, FolderPress version, the action you tried, and the error message. Do not post private file contents or personal file paths in public issues. FolderPress reports remain local unless you choose to share them.

## How it works

Choose local files or folders, review the analysis, then choose Compress or Decompress. Files keep their names, formats, and locations. macOS transparently decompresses their data when opened. FolderPress verifies staged contents before replacement and skips files that cannot safely be processed or offer no allocation saving.

Keep a backup and close apps editing selected files. Existing files are processed; newly added files are not automatically compressed. Snapshots and clone sharing can affect actual space reclaimed.

No account, telemetry, advertisements, or network access are built into the app.
